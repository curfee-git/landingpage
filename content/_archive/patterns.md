## `pattern.7` Zwischenfassung „Generierter Code ignoriert dein Wiki" (Philipps Beobachtung aus dem Interview, am Abend ersetzt)

- de: Trifft generierter Code auf Konventionen, die nur dokumentiert sind, werden sie mit hoher Wahrscheinlichkeit ignoriert. Wie bei jemandem mit zu viel Arbeit: Er nimmt die Abkürzung. Solange niemand kontrolliert, gilt alles, und solange kein Fehler auffällt, passiert nichts.
- en (Generated Code Ignores Your Wiki): When generated code meets conventions that only exist as documentation, they most likely get ignored. Like someone with too much on their plate: they take the shortcut. As long as nobody checks, everything counts, and as long as no error surfaces, nothing happens.
